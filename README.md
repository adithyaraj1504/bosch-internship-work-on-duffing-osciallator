# Bosch Internship Work: Duffing Oscillator Operator Learning & Neural Architectures

This repository contains experimental implementations, neural operator models, and recurrent baseline architectures applied to non-linear dynamical systems (specifically the Duffing oscillator) as part of research work at Bosch Global Software Technologies.

## 📂 Repository File Index & Descriptions

* osch-internship-ann-rnn-lstm-gru.ipynb — Baseline recurrent neural network models (ANN, RNN, LSTM, GRU) implemented for time-series forecasting and sequence modeling of non-linear oscillator dynamics.
* osch-internship-fno-lno-deeponet-correct.ipynb — Operator learning implementations comparing Fourier Neural Operators (FNO), Local Neural Operators (LNO), and DeepONet frameworks on continuous dynamical system trajectories.
* osch-internship-v-oformer-f-former-g-oform...ipynb — Advanced operator transformer architectures (V-Oformer, F-Former, G-Oformer variants) designed for map-based functional operator learning.
